# VirtualR – Modern React Landing Page

A modern SaaS-style landing page built using React and Tailwind CSS with a clean, responsive, component-based design.

---

## 🚀 Features
- Hero, Features, Pricing, and Testimonials sections
- Component-based UI architecture
- Responsive layout using Flexbox and Grid
- Utility-first styling with Tailwind CSS
- Fast development with Vite bundler

---

## 🛠 Tech Stack
- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)

---

```bash
git clone https://github.com/Vansh931/virtualr.git
